# ⚡ ClipStream - Universal Video & Audio Downloader

A modern, fast, full-stack video downloader web application built with Python Flask, `yt-dlp`, and FFmpeg.

## ✨ Features
- Multi-Platform Support (YouTube, TikTok, Twitter/X, Instagram, Facebook, Reddit, etc.)
- Full HD 1080p, 720p, and MP3 audio extraction
- Real-time download progress tracking
